# 🩺 Breast Cancer Predictive Modeling

Machine Learning project for predicting whether a breast tumor
is benign or malignant using the Breast Cancer Wisconsin
(Diagnostic) dataset.

## 🚀 Project Overview

This project applies machine learning techniques to classify
breast tumors based on diagnostic features.

## 🧠 Models Used

- Logistic Regression
- Decision Tree
- Random Forest

## 🔬 Workflow

1. Data loading
2. Data preprocessing
3. Exploratory Data Analysis
4. Feature scaling
5. Model training
6. Model evaluation
7. Confusion matrix
8. ROC-AUC analysis
9. Prediction

## 📊 Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
